[pnpm](<https://github.com/pnpm/pnpm>) like npm. But more easy to manage package.

```shell
npm install pnpm -g
pnpm i
pnpm up
npm/pnpm run dev/build/preview
```

Open link <https://localhost:5173/> in your browser

## Overview

A very classic countdown example by Mithril & Jsx

- mithril jsx code style
- codesplit build by route
- xhr get data
- some tailwind css useage

![screenshot](https://github.com/zsj1029/vite-project/blob/master/pic.jpg?raw=true)
